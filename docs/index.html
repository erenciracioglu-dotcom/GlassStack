GlassStack

Your PC at a glance, right on the taskbar.

A tiny system monitor for Windows 11: a slim strip on the taskbar, a 3D overview on a hotkey, and detail windows that show what is behind every number.

The strip

An 8-pixel strip stacked on the taskbar, one coloured slot per metric: memory, GPU memory and workload, two disks, Wi-Fi and CPU. No text, just shape and colour.

Rest the pointer on it for a second and every value pops up. Click a slot to open its details.

The 3D overview

Hold Ctrl+Shift and press Space: every graph appears as a frosted-glass card. Tap Space to move through the deck, let go to open the focused one.

The details

Each area gets a window with its large graph, every related graph, a details panel and the processes behind the numbers.

  • Click any small graph to make it the large one; the strip follows.
  • Point at a graph for the exact value at any moment.
  • End a task, open its folder, spot a handle leak.

First start

Unzip anywhere and run GlassStack.exe. The exe is not code-signed, so Windows SmartScreen may warn the first time: choose “More info”, then “Run anyway”. Or build it yourself from the source:

git clone https://github.com/erenciracioglu-dotcom/GlassStack.git
cd GlassStack
build.bat
